# IEEE SSCS Student Circuit Contest 2026

Integrated MOX Sensor Interface in 180 nm CMOS Technology

---

## Overview

This repository contains the complete documentation of the project developed by the IEEE SSCS Student Chapter at Universidad Distrital Francisco José de Caldas for the IEEE SSCS Student Circuit Contest 2026.

The objective was to design and simulate an integrated interface for a metal-oxide (MOX) gas sensor using only the components allowed by the competition.

## Objectives

- Design an integrated analog front-end.
- Maximize the use of the allowed components.
- Generate a digital output without using an ADC.
- Validate the design through simulation.
